# Tessery - Getting Started

## Overview
Self-hosted platform to design software systems visually, generate code, and deploy.

## Workflow
```
Visual Design --> Code Generation --> Build --> Deploy
     |                 |               |         |
  Drag & Drop     TypeScript/Go    Docker    Production
  Components      API Routes       CI/CD     Monitoring
```

## Quick Start
```bash
git clone https://github.com/martian56/tessery.git
cd tessery
docker-compose up -d
# Open http://localhost:3000
```

## Features
| Feature | Description |
|---------|-------------|
| Visual Designer | Drag-and-drop system design |
| Code Gen | Auto-generate from design |
| Deploy | One-click deployment |
| Self-Hosted | Full control of your data |
